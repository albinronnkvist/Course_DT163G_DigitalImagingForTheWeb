# DT163G - Digital Imaging for the Web

Image Theory, Editing, and Optimization for the Web.

In this course, I learned the fundamentals of image theory, including file types, optimization, and how graphics are implemented on the web. I also gained experience in image and video editing using Photoshop and Premiere Pro. For the final project, I developed a static website designed as a template for an online store. The focus was on digital image processing and design planning. The website was built using HTML and CSS, with JavaScript added for interactive functionality.
